# Contributing

Contributions are welcome when they improve correctness, testability, accessibility, or safety within the supported boundary.

Before opening a pull request:

1. Keep tests offline by default; do not add live credentials or request captures.
2. Preserve submit-once and fresh-read verification semantics.
3. Do not add credential import, multi-account scheduling, CAPTCHA handling, anti-detection, or circumvention features.
4. Describe platform behavior as observed and changeable, never as an official or guaranteed API contract.
5. Confirm that test fixtures contain only synthetic identifiers and content.

Pull requests that broaden the project into an account-automation or evasion tool will not be accepted.
